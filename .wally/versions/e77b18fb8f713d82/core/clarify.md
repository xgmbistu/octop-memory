# Clarify 阶段指引

定位本任务 `01-clarify.md`，先读已有需求和用户约束，整理目标用户/场景、范围、成功判据与依赖。用户预置输入充分时直接校验并写入结论，不为完成访谈而重复提问。

仅对会影响实现的缺口提问，问题简短、聚焦，允许用户直接修正假设；与答案无关的资料整理可继续。检查关键假设、异常场景、最小可交付范围和约束冲突，不固定要求 Discovery/Challenge 轮数或额外确认仪式。

Bug/性能任务补齐问题判据、输入状态、现象、期望、已有复现/基线证据和环境限制。项目配置中的专项检查按影响加载。

只把需求事实、决策、风险与来源写入本任务 Clarify；不覆盖其他任务，不新建第二份 PRD。已有有效文档按本次请求局部更新；用户只要求讨论时不改产物。重大未决问题解决后进入 Plan，按交互规则判断是否需要等待用户。
