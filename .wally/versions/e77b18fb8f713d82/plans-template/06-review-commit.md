# 06. Review + Commit

## 最终 Review

实际 diff、变更后的证据复核、发现/修复结果、Plan 偏差、缺陷闭环与未解决风险。

## 时间记录审计

核验各阶段开始/结束、耗时、对话轮次和产物齐全；补齐仅用真实对话证据。无证据空白/漏记/集中后补不通过，退回缺步重做并当场记时，禁止进入 Commit。

## 外部系统与资源

按项目配置和授权记录实际状态/处理结果，或不适用依据；不得虚报成功。

## 提交准备

- Message 与显式暂存文件：
- Token 报告：已启用时实际执行对应入口并读取结果；未启用/不完整如实记录。
- Overview 更新与适用门禁结论：
- Commit/Push 授权及停止边界：

## 执行结果

Commit、Push 的实际结果与失败原因。只完成准备时明确写“未执行”，不提前标记已提交。

## 知识库证据

按任务绑定的 `core/knowledge.md` 执行本阶段职责。记录实际读取的相关路径、源码核验、缺口、受影响文档及更新/无需更新依据、校验结果；最终 Review 对照完整任务 diff 复查。
